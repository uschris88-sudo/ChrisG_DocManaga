# DocManaga Developer Portal

Welcome to the DocManaga Developer Platform.

DocManaga provides a secure document management API that allows businesses to store, manage, and share documents programmatically.

## Key Features

- Upload and store documents
- Secure document sharing
- Password protection
- Merge multiple documents
- Download and manage files

## Base API URL

`https://api.docmanaga.com/v1`

## Quick Example

```bash
curl -X GET https://api.docmanaga.com/v1/documents \
	-H "Authorization: Bearer YOUR_API_KEY"
```
